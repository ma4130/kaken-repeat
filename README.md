# まねっこムシ

話しかけた言葉を、虫が同じように言い返すブラウザゲームです。

**遊ぶ:** https://ma4130.github.io/kaken-repeat/

## 遊び方

1. 下に並んだ虫から好きな虫をえらぶ
2. 「🎤 マイクをオン」を押してマイクを許可する
3. 話しかけると、話し終わったところで虫が同じことを言い返す

| 虫 | 名前 | 声 |
|---|---|---|
| コオロギ | リリー | 高い声・「リリッ」 |
| テントウムシ | テンコ | いちばん高い声・「ポポッ」 |
| ミツバチ | ブンタ | ブルブルふるえる声・「ブーン」 |
| カブトムシ | カブキチ | 低い声・「ドスン」 |
| セミ | ミンミン | ゆれる声・「ミーン」 |

- 「声の高さ」スライダーで声の高さを変えられる（虫を切りかえると、その虫の高さに戻る）
- えらんだ虫は次に開いたときも覚えている

マイクは https か localhost でないと使えません。
