# まねっこコオロギ

話しかけた言葉を、コオロギの「リリー」が高い声でそのまま言い返すブラウザゲームです。

## 遊び方

1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 「🎤 マイクをオン」を押してマイクを許可する
3. 話しかけると、話し終わったところでリリーが同じことを言い返す
4. マイクが使えないときは、下の入力欄に文字を打って「言う」でも話せる

- 「声の高さ」スライダーでリリーの声の高さを変えられる
- まねした回数 5 回ごとにリリーのレベルが上がる
- Chrome / Edge では音声認識で言った言葉が吹き出しに出て、「おぼえたことば」にたまっていく

## 公開

GitHub Pages を有効にすると（Settings → Pages → main ブランチ / root）スマホからも遊べます。
マイクは https か localhost でないと使えません。
